## Requirements

Tested on Ubuntu 24.04
Submodules must be initialized. Currently VSCode does not offer this feature, and they must be initialized through terminal using ssh.

1. Python >= 3.12.3
2. Virtual Environment -> sudo apt install python3.12-venv
    Use source ./vit/bin/activate to activate the project python environment.
3. PyBind11 (Already included in the enviroment)
4. Intel DPC++/C++ Compiler (Installer require for recompiling, runtime versions available through pip)
5. Cuda toolkit (Optional. Only required if using Vit-GPU) Version tested 12.6
6. OpenCV (Optional. Only required for test cases)
